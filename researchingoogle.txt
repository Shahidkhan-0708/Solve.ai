python
import requests
from bs4 import BeautifulSoup

def scrape_study_material(url):
    headers = {'User-Agent': 'Mozilla/5.0'}
    response = requests.get(url, headers=headers)
    
    if response.status_code == 200:
        soup = BeautifulSoup(response.text, 'html.parser')
        
        # Remove script and style elements
        for script in soup(["script", "style"]):
            script.decompose()
            
        # Extract main text content
        text = soup.get_text(separator=' ')
        clean_text = " ".join(text.split())
        return clean_text
    return None

import openai

def generate_quiz(scraped_context):

⚠️ Key Risks & Legal Guardrails
Copyright & Terms of Service: Scraping public educational blogs is generally fine, but scraping proprietary portals (like Canvas, Blackboard, or paid test-prep sites) can violate their Terms of Service. Always check robots.txt.
Rate Limiting: Universities will quickly block your IP if your scraper hits them too fast. Introduce random delays (time.sleep) between requests.
Hallucination: LLMs love to sound confident even when they are wrong. Use Retrieval-Augmented Generation (RAG) to anchor the AI strictly to the text you scraped, rather than its pre-trained general knowledge.

To make the solution instantaneous and avoid the 2–3 minute processing lag of platforms like NotebookLM, you must optimize your backend architecture:
Scrape via Markdown Only: Do not scrape full HTML or images. Use tools like Crawl4AI or Firecrawl to get raw, lightweight markdown. Less text means faster API processing.
