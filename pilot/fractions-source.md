# Fractions: equal parts and adding amounts

Draft original source pack for checking Solve on a second subject. Independent subject review is required before advertising this as an approved lesson.

A fraction describes equal parts of one whole. The denominator tells how many equal parts the whole is divided into. The numerator tells how many of those parts are being counted.
For 3/4, the whole is divided into four equal parts and three are counted. A denominator cannot be zero.
Amounts must refer to the same-sized whole before their fraction labels can be combined as parts of that whole.

Equivalent fractions name the same amount. Multiplying both numerator and denominator by the same positive integer preserves the value.
For example, 1/3 = 2/6 because each third can be divided into two sixths. Two sixths cover the same amount as one third.
The reverse process simplifies a fraction: dividing numerator and denominator by a common positive factor preserves the value. For example, 3/6 = 1/2.
Changing only the numerator or only the denominator generally changes the amount.

To add fractions, first express both amounts using equal-sized parts with the same denominator. Then add the numerators and keep that denominator.
For example, 1/3 + 1/6 = 2/6 + 1/6 = 3/6 = 1/2.
Adding the denominators directly gives 2/9, which is incorrect for this sum. It changes the size of the parts rather than just counting the same-sized parts.
A common denominator must be a common multiple of the original denominators. The least common multiple is convenient, but a larger common multiple also works.
For 1/4 + 1/6, use twelfths: 3/12 + 2/12 = 5/12.
For 2/3 + 1/4, use twelfths: 8/12 + 3/12 = 11/12.
For 3/4 + 2/3, use twelfths: 9/12 + 8/12 = 17/12, which is 1 and 5/12.
For 1/2 + 1/8, use eighths: 4/8 + 1/8 = 5/8.

A useful reasoning check is to explain what the denominator means, why equivalent fractions preserve the amount, and why denominators must match before numerators are added.
A final number alone does not show those reasoning steps. Trace the conversion and the addition, then simplify if a common factor exists.
